Pipeline 01

Direct upload keeps file traffic out of serverless functions.

POST/api/analysesValidates metadata with Zod and creates analysis, candidate, and document rows.
PUTPresigned R2 URLsEach document gets a MIME-bound, server-generated object key.
RETRYBounded concurrencyUploads run with configurable concurrency and three transient-error attempts.
PATCHDocument state updateUploaded, failed, and retry actions update each file independently.

06 / 14
Pipeline 02

Format-aware extraction, with OCR only when it earns its keep.

PDFunpdf extracts page text; quality checks detect scanned or unreadable documents.
DOCXmammoth reads paragraphs and tables without executing embedded content.
XML + TXTXML blocks DTD/entities; TXT uses forgiving UTF-8 decoding.
States move through UPLOADING, UPLOADED, EXTRACTING, OCR, NORMALIZING, INDEXING, READY, or FAILED.

08 / 14
Scoring logic

The final rank is deterministic, not vibes.

Final score = 50% semantic + 30% keyword + 20% required-skill coverage
SemanticCosine similarity compares job-description embedding with each resume embedding.
KeywordExplicit weighted requirements are extracted and matched against resume text.
CoverageRequired skills are tracked as matched and missing skills for reviewer transparency.
